# Principles
- **Context Discipline**: Context window capacity is finite and irreversible. All commands, queries,
  listings, searches, and file reads must be strictly bounded in output before execution. Never emit
  unmetered or streaming output directly into context.
- **Direct Communication**: Deliver concise, precise, and direct responses without conversational filler,
  boilerplate pleasantries, or unprompted recaps of modified files.

4. Redundant Built-in Tools (6 Tools)

Pruned in both custom agents (~3,980 tokens saved)
list_dir Default Only

Recursive directory listing tool.

Subsumed by Shell: run_command running ls -la or tree -L 2 is faster, formatted, and strictly bounded.
grep_search Default Only

Ripgrep regex search over files.

Subsumed by Shell: run_command running rg -n "pattern" gives identical results without injecting a 50-line JSON schema.
find_by_name Default Only

Filename search using fd.

Subsumed by Shell: find . -name "pattern" or fd via shell handles file search with zero token tax.
ask_question Default Only

Renders interactive multi-choice question modals.

Natural Chat: Models ask questions directly in conversation text; a complex modal schema is unnecessary.
generate_image Default Only

Image generation via Imagen/text prompts.

Niche Tool: Non-essential for software engineering and coding workflows.
schedule Default Only

Sets one-shot timers or cron jobs.

Niche Tool: Timers are handled via CLI client scheduling or standard shell timers.

5. Default System Prompt Sections

Opted out via excludeDefaultComponents: true (~3,000 tokens saved)
<artifacts> (~1,250 tokens) Default Only

Extensive instructions on markdown artifacts, alert callouts ([!NOTE], [!WARNING]), Mermaid diagrams, and scratch scripts.

Anxiety Reassurance: The Antigravity IDE and CLI render markdown artifacts and Mermaid flowcharts automatically on the client. Removing 1,250 tokens of styling boilerplate does NOT stop artifacts from working.
<slash_commands> (~420 tokens) Default Only

Prescriptive list instructing the model to suggest /goal, /plan, /boost, /schedule, and /teamwork-preview.

Client-Side Shortcuts: Slash commands are intercepted directly by the CLI client. The LLM does not need a static dictionary of commands to function.
<conversation_transcript> (~360 tokens) Default Only

Technical specification of JSONL trajectory logs, step types (PLANNER_RESPONSE, USER_INPUT), and truncation flags.

Internal Daemon Task: Trajectory logging is written by the Antigravity language server process; models do not format or create these files.
<messaging> & <subagents> Boilerplate (~540 tokens) Default Only

Generic explanations of asynchronous message queues, reactive wakeups, and subagent descriptions.

Preserved Hooks: Post-invocation hooks and event loops are maintained in the host daemon; omitting prompt boilerplate changes nothing about runtime wakeups.
